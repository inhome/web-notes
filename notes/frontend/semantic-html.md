# Semantic HTML

Choose elements for their meaning before adding classes.

```html
<main>
  <article>
    <h1>Release notes</h1>
    <p>A short description of the update.</p>
  </article>
</main>
```

## Caveats

Use a button for an action and an anchor for navigation. Keep one main landmark per page.

## Check

Navigate the page with a keyboard and inspect the heading order.
